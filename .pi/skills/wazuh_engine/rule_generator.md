# SKILL: WAZUH RULE GENERATOR SCHEMA

## ĐỊNH DẠNG XML CHUẨN DÀNH CHO WAZUH LOCAL_RULES.XML

```xml
<group name="agentwazuh_custom,">
  <rule id="{rule_id}" level="{level}" frequency="{frequency}" timeframe="{timeframe}">
    <if_matched_sid>{parent_sid}</if_matched_sid>
    <match>{match_pattern}</match>
    <description>{rule_name} (Generated by AgentWazuh)</description>
    <mitre>
      <id>{mitre_id}</id>
    </mitre>
  </rule>
</group>
```

## DẢI RULE ID QUY ĐỊNH
Cấu hình mới phải thuộc dải Rule tự định nghĩa: `100100` đến `100999`.
